# DARYXX

A mobile banking UI prototype built with Expo and React Native. The app includes an onboarding and sign-in flow, account dashboard, simulated transfers and bill payments, recent activity, and profile/settings screens.

## Requirements

- Node.js LTS with npm
- Expo Go on a phone, or an Android/iOS simulator

## Run

```powershell
npm install
npm run start
```

Scan the QR code with Expo Go, or use `npm run android` / `npm run ios` with a configured simulator. Use `npm run typecheck` to run the TypeScript check.

All balances, identities, transfers, and payments are mock data. This prototype does not connect to a bank or process real transactions.
